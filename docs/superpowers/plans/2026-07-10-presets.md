# Presets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated `/presets` page that opens code-backed JSON presets as editable new document drafts.

**Architecture:** Add a typed preset registry under `src/features/presets/`. Reuse existing new-document routes and editors by passing preset data as `initialData` when `?preset=<slug>` matches the requested document type. Keep presets out of the database.

**Tech Stack:** React 19, TanStack Router, TypeScript, Vitest, existing document schemas.

## Global Constraints

- Do not add dependencies.
- Keep presets code-backed in the repo.
- Unknown or mismatched preset slugs fall back to blank defaults.
- First preset is an ISTT cover page extracted from `Refrence/index.html`.

- [ ] **Step 1: Write failing tests**

```ts
import { describe, expect, it } from "vitest";
import { documentPresets, getDocumentPreset, getDocumentPresetData } from "./presets";

describe("document presets", () => {
  it("includes the ISTT cover page preset", () => {
    const preset = getDocumentPreset("istt-cover-page");
    expect(preset?.type).toBe("cover_page");
    expect(preset?.data.instituteShort).toBe("ISTT");
    expect(preset?.data.logoDataUrl).toMatch(/^data:image\/webp;base64,/);
  });

  it("returns cloned data only for the requested type", () => {
    const cover = getDocumentPresetData("istt-cover-page", "cover_page");
    expect(cover?.type).toBe("cover-page");
    expect(getDocumentPresetData("istt-cover-page", "index_sheet")).toBeNull();
    expect(getDocumentPresetData("missing", "cover_page")).toBeNull();
  });

  it("exposes presets for listing", () => {
    expect(documentPresets.map((preset) => preset.slug)).toContain("istt-cover-page");
  });
});
```
